浏览器渲染管线简述

当你在地址栏输入 URL 并回车，浏览器会先进行 DNS 解析，找到对应服务器的 IP 地址，然后通过 TCP 三次握手建立连接，如果是 HTTPS 还会多出 TLS 握手的过程。连接建立后，浏览器发送 HTTP 请求，服务器返回响应报文。

拿到 HTML 之后，渲染引擎开始工作：首先解析 HTML 构建 DOM 树，同时解析 CSS 构建 CSSOM，二者合并生成渲染树。随后进入布局阶段，计算每个节点的几何信息，再进行绘制，把像素一层层画到屏幕上。现代浏览器为了性能引入了合成，通过 GPU 将图层合并，减少重排重绘的开销。

需要注意的是，JavaScript 的执行会阻塞解析器，所以脚本通常放在底部或者加 defer 属性。而 async 脚本下载和执行都不阻塞解析，但执行顺序不确定，适合独立模块。
