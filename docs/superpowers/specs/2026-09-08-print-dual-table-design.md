# 双表 A4 打印（左右均分 + 测量分页）设计

日期：2026-09-08  
状态：已确认（方案 2）

## 背景与目标

在 Vue3 demo 中新增打印页：同一套表格数据左右并排打两份结构相同的表，中间留缝；数据按行数平均分配到左/右；单元格可换行导致行高不固定时，避免超出 A4 时半行被截断。

## 已确认需求

| 项 | 选择 |
|----|------|
| 布局 | A：左右并排，中间缝隙 |
| 数据 | 一套数据按行数均分到左/右 |
| 列 | 每表约 2～3 列（序号 / 名称 / 备注，备注可换行） |
| 分页 | A：按页分页，一行不跨页切开；第 2 页起仍左右并排 |
| 纸张 | C：默认 A4 纵向，预览可切换横向并重测 |
| 实现 | 方案 2：DOM 实测行高后贪心装页 |

## 页面结构

- 路由：`/print-dual-table`
- 导航：App 菜单增加「双表打印」
- 工具栏：打印、纸张方向（纵向/横向）、示例数据条数、中间缝宽
- 屏幕预览：按 A4 比例展示多页，每页 = 左表 \| 缝 \| 右表
- 打印区：与预览同源结构，`window.print()` 时只输出该区域

## 分页算法

1. **均分**：`mid = ceil(n / 2)`，左 `rows[0..mid)`，右 `rows[mid..n)`。
2. **测量**：隐藏测量容器按「单表可用列宽」渲染行，读取每行 `offsetHeight`（含换行）。
   - 单表列宽 = `(A4 内容宽 − 缝宽) / 2`
3. **装页**：可用高度 = A4 高 − 页边距 − 表头高；左、右各自贪心装行，一行不拆；装不下则新开一页。
4. **对齐页数**：`pageCount = max(左页数, 右页数)`；某侧某页无数据时仍渲染空表头占位。
5. **方向切换**：改纵向/横向后重算纸面尺寸、列宽与可用高，再执行 2～4。

截断问题靠「按实测高度切页」解决，不依赖浏览器对 `tr` 的 `break-inside` 行为。

## 打印样式

- `@page` 按方向设置 A4；页边距约 10–12mm
- 每页 `.print-page`：`page-break-after: always`，末页取消
- 页内 flex：左表 | 固定缝（默认约 8mm，可调）| 右表
- 表格 `table-layout: fixed`，备注列允许换行
- 屏幕预览用 mm + 缩放模拟纸面
- `@media print` 隐藏导航与工具栏，仅保留打印区

## 非目标

- 不引入 html2canvas / jsPDF
- 不做服务端生成 PDF
- 不做复杂表头合并 / 跨表合并单元格
- 不做真实业务数据对接（仅 mock，条数可调）

## 验收标准

1. 左右两表结构相同，中间有可见缝隙。
2. 同一套数据按行数均分到左、右。
3. 备注换行导致行高不一时，打印预览/打印中不出现半行被切。
4. 纵向/横向可切换，切换后重新分页且预览正确。
5. `window.print()` 只打表格页，不含站点导航。
